Chapter One

Midnight Rain

The scent of rain and old parchment always had a way of anchoring Julian’s thoughts when the city quieted down. On the heavy oak desk sat an untamable stack of leather-bound journals, their corners worn smooth by years of restless revision. Outside, cobblestones glistened beneath the amber glow of gas lanterns, yet inside this quiet room, time felt suspended.

He dipped the nib into deep sepia ink, paused for the briefest breath, and allowed the first sentence of the long-forgotten chronicle to etch itself onto the clean page.

Designed Specifically for Prose Authors

Code editors are built for compilers. Novellized is tailored entirely for the rhythm of literary prose.

Live Book Typography

Powered by TipTap and ProseMirror. Paragraph indentation, serif typographic scales, and comfortable eye-line margins format your text into a book page as you write.

Focus Mode & Typewriter Scroll

Only the active paragraph remains in high focus while surroundings gently fade. Concurrently, typewriter scrolling locks your active typing line at ~42% vertical eye level.

Dual-Engine Architecture

Switch seamlessly between formatted TipTap Live View and raw Monaco Markdown with zero buffer loss, no format destruction, and zero sync conflicts.

Scrivener-Style Binder

Hierarchical structure from Act to Chapter to Scene. Track project-wide word milestones, daily writing sprints, reading duration, and scene status at a glance.

Jargon-Free Checkpoints

Built-in snapshot management powered by isomorphic-git under the hood. Save version checkpoints, view scene differences, and rollback revisions without terminal commands.

One-Click Book Compiling

Compile your entire novel into validated EPUB 3 ebooks, publication-ready PDFs via headless printing, or responsive printable HTML viewports on demand.

Automated Updates via Linux APT

Install Novellized Studio once, and stay seamlessly updated through Debian/Ubuntu package management.

1

Option A: Quick One-Line Terminal Install

Automatically downloads and installs the latest verified .deb package for your system:

curl -fsSL https://novellized.github.io/install.sh | bash
2

Option B: Standard APT Package Repository

Add the repository source entry directly to your system's package list:

echo "deb [trusted=yes] https://novellized.github.io/apt stable main" | sudo tee /etc/apt/sources.list.d/novellized.list
sudo apt update && sudo apt install novellized-studio
